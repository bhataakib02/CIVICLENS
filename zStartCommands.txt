=== CIVICLENS STARTUP COMMANDS ===

1. Start Infrastructure (PostgreSQL & Redis):
   docker compose up -d

2. Backend API Server (FastAPI on http://localhost:8000):
   cd backend
   .venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

3. Frontend Admin Console (Next.js on http://localhost:3001):
   cd frontend\admin
   npm run dev

4. Frontend Citizen Web App (Next.js on http://localhost:3000):
   cd frontend\web
   npm run dev

5. Seed Real Opportunity Sources & Accounts:
   cd backend
   .venv\Scripts\python.exe -m app.seeds.seed_all

6. Run Real Opportunity Live Crawler & Diagnostics:
   cd backend
   .venv\Scripts\python.exe verify_real_sources_ingestion.py

7. Run Backend Automated Test Suite:
   cd backend
   .venv\Scripts\python.exe -m pytest tests/ -v
