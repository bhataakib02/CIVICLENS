# Security Policy

CivicLens handles potentially sensitive citizen information and documents.

## Reporting

Do not disclose suspected vulnerabilities publicly. Report security issues privately to the project maintainers.

## Security priorities

- Authentication and authorization
- Object-level access control
- Citizen document protection
- PII minimization
- Secrets management
- Upload validation and malware scanning
- Auditability
- Prompt injection and RAG poisoning resistance
- Dependency and container security

Security fixes should include regression tests where practical.
