# CivicLens Documentation

This directory contains the source-of-truth engineering documentation for CivicLens v1.0.

CivicLens is an AI-assisted public-service navigation platform. The system helps citizens discover government schemes, evaluate eligibility using deterministic policy rules, understand evidence, process supporting documents, and navigate application workflows.

## Documentation hierarchy

1. Product requirements define what the system must do.
2. Architecture defines how the system is organized.
3. Database and API contracts define implementation interfaces.
4. AI and security documents define specialized system behavior.
5. Testing and operations documents define quality and production readiness.
6. ADRs record important architectural decisions.

## Source-of-truth rule

Requirements, versioned policy rules, database migrations, and OpenAPI contracts are authoritative. Implementation must conform to them or explicitly update the relevant documentation and ADR.
